# Misión Cero Riesgos

Juego web educativo sobre riesgos de seguridad en fábrica.

## Uso
Abre `index.html` en un navegador. No requiere instalación, backend ni conexión a internet.

## Controles
- Flechas o WASD: desplazamiento.
- Barra espaciadora: aplicar control.
- En móvil: controles táctiles.

Contenido simulado. No sustituye los procedimientos oficiales de seguridad.
